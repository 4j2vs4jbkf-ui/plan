# plan

시험 날짜, 범위, 쓸 수 있는 시간을 넣으면 시험 전까지 매일 할 일을 나눠 주는 공부 계획 앱.
로그인 없음. 데이터는 휴대폰 브라우저에 자동 저장.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 계획 알고리즘, 저장) |
| `manifest.webmanifest` | 홈 화면에 추가할 때 이름·아이콘 |
| `sw.js` | 인터넷이 없어도 열리게 하는 캐시 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 배포 (GitHub Pages)

1. github.com에서 새 저장소 `plan` 만들기 (Public)
2. Add file → Upload files → 파일 5개 올리고 Commit
3. Settings → Pages → Branch `main` / `(root)` → Save
4. 1~2분 뒤 `https://아이디.github.io/plan/` 접속
5. 휴대폰에서 공유 → 홈 화면에 추가

## 수정 후 반영

`index.html`을 고쳐서 다시 올린 뒤 `sw.js`의 `VERSION`을 `plan-v2`처럼 올리면 휴대폰에서도 새 버전이 확실히 뜸.

## 계획 짜는 방식

- 과목별 필요 시간 = 범위 시간 + 목표 등급별 복습(1등급 50% ~ 5등급 20%) + 최종 점검
- 하루 계획 가능 시간 = (공부 가능 시간대 − 고정 일정) × 공부/휴식 비율 − 여유 비율, 하루 최대치로 자름
- 매일 남은 양을 남은 기간의 시간에 비례해 나눠 배치. 중요도 높은 과목이 같은 날 먼저 들어감
- 복습은 시험 7일 전부터, 최종 점검은 2일 전부터
- 못 끝낸 과제는 다음 날 앱을 열 때 자리가 있는 가장 가까운 날로 이동. 나머지 계획은 안 건드림
